# ✏️ 60秒ファイター！

**60秒でお絵描き → 描いた形と色で能力＆必殺技が自動決定 → スマブラ風2D大乱闘！**

ブラウザだけで完結する、手描きスケッチブック風のマルチプレイヤー2D対戦アクションゲームです。  
バックエンドサーバー不要で、**GitHub Pages + PeerJS（WebRTC）** で最大4人のオンライン対戦とオフラインCPU戦の両方を楽しめます。

---

## 🎮 主な特徴

- **60秒リアルタイムお絵描き（全36種類のお題）**
  - バトル・ファンタジー / メカ・SF / 生き物 / 食べ物 / ゆるキャラ・ネタの **5カテゴリ・全36種のお題**（剣士・ドラゴン・侍・戦車・UFO・ネコ・サメ・ラーメン・おすし・お相撲さん・だるま等）から自由にキャラクターを描画。
  - 対戦相手が描いている線がリアルタイムでミニキャンバスに同期表示されます。
  - 残り10秒で「あと10秒！」の警告演出＆カウントダウン効果音！
- **手描きキャラクター自動解析＆必殺技生成**
  - 描いた線の量・サイズ・縦横比・丸み・手足・武器・翼・角・色の割合を自動解析。
  - 8項目（攻撃・防御・速度・ジャンプ・重量・リーチ・つかみ・空中ジャンプ）のステータスと、特徴に応じた必殺技（斬撃・炎・雷・氷・星・翼ダッシュ・地震など）を自動生成します。
- **スマブラ風 2D バトルアクション & 安心の復帰システム**
  - 描いた線そのものが手描きアニメーションしながらステージ上で戦います。
  - ダメージ％に応じたふっとばし、空中ジャンプ、**上＋必殺技の「復帰ジャンプ」**、ステージ端での **「崖つかまり」**、ガード、つかみ投げ、4種のアイテム（ハンマー・爆弾・回復キノコ・巨大化キノコ）を搭載。
  - 3つの手描きステージ：**学校のノート** / **画用紙** / **ホワイトボード**。
- **最大4人オンライン対戦 & CPU戦**
  - 6桁の部屋コードで友達と簡単マッチング（1対1 / 2対2チーム戦 / 最大4人バトルロイヤル）。
  - ストック制（3機） / タイム制（2分）を選択可能。
  - チャット＆スタンプ機能、退出通知、**ホスト引き継ぎ（Host Migration）** に対応。
  - ひとりでも「CPU戦」から登録不要ですぐに遊べます。CPUの強さは **5段階（🐣よわい / 🙂ふつう / 😤つよい / ⚡げきつよ / 🔥バカ強い）** から一括＆CPUごとに個別設定できます。

## 🕹 操作方法

### キーボード

| アクション | キー |
| --- | --- |
| 左右移動 | `A` / `D` または `←` / `→` |
| ジャンプ / 空中ジャンプ | `W` / `↑` / `Space` |
| すり抜け床から降りる | `S` / `↓` + ジャンプ（または下2回） |
| 通常攻撃 | `J` / `Z` |
| 強攻撃（スマッシュ） | `K` / `X` |
| 必殺技 | `L` / `C` |
| 復帰ジャンプ（上必殺） | `W` / `↑` を押しながら `L` / `C` |
| 崖つかまり | ステージ端に近づくと自動でつかまります（ジャンプや方向キーで復帰） |
| ガード（シールド） | `S` / `↓` / `Shift` |
| つかみ（ガード崩し） | `U` / `E` |

> スマホ・タブレットでは画面上部の「📱 タッチ操作」ボタンからオンスクリーンパッド（`↑復帰` ボタン含む）を表示して遊べます。

```text
    ├── stages.js            # 3ステージの地形設定と手描き背景レンダリング
    ├── battle.js            # スマブラ風2D物理・戦闘・アイテム・ネット同期エンジン
    ├── ai.js                # 復帰・アイテム回収・攻防判断を行うCPU AI
    ├── sfx.js               # Web Audio API によるゼロ依存プロシージャル効果音
    └── network.js           # PeerJS (WebRTC) ホスト権威通信・ハートビート・ホスト引き継ぎ
```

## 🚀 GitHub Pages への公開方法

静的ファイルのみで構成されているため、そのまま GitHub Pages で公開できます。

1. GitHub で新しいリポジトリを作成し、このフォルダ内のファイルをルート（または `docs/`）に push します。
2. リポジトリの **Settings → Pages** を開きます。
3. **Source** で `Deploy from a branch` を選び、ブランチ（例：`main`）とフォルダ（`/ (root)`）を指定して **Save** をクリックします。
4. 数十秒後に発行される `https://<ユーザー名>.github.io/<リポジトリ名>/` にアクセスして完了です！

### ローカルでの動作確認

ES Modules を使用しているため、簡易ローカルサーバー経由で開いてください：

```bash
# Python 3 がある場合
python -m http.server 8080

# Node.js がある場合
npx serve .
```

ブラウザで `http://localhost:8080` を開くと遊べます。

## 💡 静的サイトでの収益化・広告枠について（GitHub Pages / Cloudflare Pages）

純粋な静的サイト構成のため、バックエンドなしで以下の収益化オプションを後から簡単に組み込めます：

- **トップ画面・リザルト画面の下部バナー枠**：バトル中や60秒お絵描き中の操作・視界を邪魔しないよう、トップ画面やリザルト画面の下部に Google AdSense や各種アフィリエイトのレスポンシブ広告枠を配置するのがおすすめです。
- **独自ドメイン＋Cloudflare Pages**：Google AdSense を導入する場合は、GitHub Pages または Cloudflare Pages に独自ドメインを設定し、`ads.txt` とプライバシーポリシーページを静的ファイルとして追加するだけで審査対応できます。
- **応援・投げ銭リンク**：GitHub Sponsors / Ko-fi / Buy Me a Coffee などの応援ボタンをトップ画面のフッターに添える構成も、ゲーム体験を損なわずに相性が良いです。
